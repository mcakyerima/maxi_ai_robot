## 🐛 Troubleshooting

### **No Audio at All**

1. **Check tablet volume** - Make sure it's not muted
2. **Check browser console** - Look for error messages
3. **Verify WebSocket connection** - Console should show "WebSocket connected"
4. **Check server logs** - Look for "🔊 Streamed X bytes to tablet"

### **Audio Still Playing from Laptop**

1. **Verify .env setting**: `USE_CLOUD_AUDIO=true`
2. **Restart the server** completely (Ctrl+C then restart)
3. **Hard refresh tablet browser** (Ctrl+Shift+R or clear cache)

### **Audio is Choppy or Delayed**

This is normal on first test - the timing estimation might need adjustment. The audio is pre-generated by Edge-TTS (Microsoft), so quality is high, but network can affect streaming.

### **WebSocket Errors**

If you see WebSocket connection errors:
1. Check firewall - Port 8765 must be open
2. Verify laptop and tablet are on same network
3. Check laptop IP address hasn't changed
